## 🚀 Featured Project

### DevFlow AI

An AI-powered application that connects GitHub repositories and answers code-related questions using Retrieval-Augmented Generation (RAG).

- **Live Demo:** [Try DevFlow AI](https://devflow-ai-pi.vercel.app/)
- **Source Code:** [View GitHub Repository](https://github.com/UzairMalik17/devflow-ai)

**Technologies:** Next.js, TypeScript, PostgreSQL, pgvector, Drizzle ORM, BullMQ, Valkey, Gemini API.

**Key Implementation Areas:**
- Repository ingestion and source-code processing.
- Code chunking and embedding generation.
- Vector storage and similarity search using PostgreSQL and pgvector.
- Asynchronous processing using BullMQ workers.
- Integration with GitHub and Gemini APIs.
- API-key availability management and scheduled recovery mechanisms.
